
2. 如果看到 `页面检测结果: null` → 当前页面不在支持范围（非搜索页/详情页）。
3. 如果看到 `记忆位置越界，已重置为默认位置` → 自动修复。
4. 如果完全无日志 → 检查 Tampermonkey 是否启用、脚本是否生效。

### 查询失败

- **`获取第 N 页失败`**：可能被亚马逊限流，减少查询页数或稍后再试。
- **「已跳转但未定位到商品」**：搜索结果排序发生变化，用 ASIN 精确匹配通常能修正，如果仍失败可重新查询。

### 历史记录迁移

旧版升级后首次运行：

- 首次打开某站点 → 旧全局历史迁移到该站点；
- 后续打开其他站点 → 该站历史为空（旧数据已迁走）；
- 如需在其他站点保留，手动重新查询即可。
