# Amazon 自然位/广告位查询 + Listing 关键词搜索

一个 Tampermonkey 用户脚本，支持所有 Amazon 站点。在搜索结果页查 ASIN 的**自然位**或**广告位**，自动跳转并高亮定位；在 Listing 详情页搜索标题、五点、描述、A+ 等区域是否包含指定关键词。

## 功能概览

| 页面类型 | 按钮文案 | 功能 |
|---|---|---|
| 搜索结果页 `/s?k=...` | `🔍 查自然位/广告位` | 输入 ASIN，查它在自然位或广告位中的「第几页第几位」 |
| Listing 详情页 `/dp/...` | `🔍 查关键词` | 输入关键词，检查标题/五点/描述/A+/详情/品牌里是否包含 |

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展（Chrome / Edge / Firefox / Safari 均可）。
2. 点击 Tampermonkey 图标 → **添加新脚本**。
3. 清空默认内容，粘贴本脚本全文。
4. `Ctrl+S` 保存。
5. 打开任意 Amazon 站点，右下角出现橙色悬浮按钮即安装成功。

## 支持的站点

只要域名是 `amazon.xx` 就支持，包括但不限于：

| 区域 | 域名 |
|---|---|
| 北美 | `amazon.com` / `amazon.ca` / `amazon.com.mx` / `amazon.com.br` |
| 欧洲 | `amazon.co.uk` / `amazon.de` / `amazon.fr` / `amazon.it` / `amazon.es` / `amazon.nl` / `amazon.se` / `amazon.pl` / `amazon.com.be` / `amazon.com.tr` / `amazon.ie` |
| 亚太 | `amazon.co.jp` / `amazon.in` / `amazon.com.au` / `amazon.sg` |
| 中东 | `amazon.ae` / `amazon.sa` / `amazon.eg` |

`smile.amazon.com` 等旧域名同样支持。

## 使用方法

### 一、查 ASIN 排名（搜索结果页）

1. 打开任意 Amazon 站点，输入关键词搜索，进入 `/s?k=...` 页面。
2. 点击右下角悬浮按钮 `🔍 查自然位/广告位`。
3. 在面板中：
   - **切换模式**：`📍 自然位` 或 `📢 广告位`（默认记住上次选择）。
   - **输入 ASIN**：直接填 10 位 ASIN，或粘贴商品链接自动提取。
   - **设置查询页数**：默认前 5 页，可调整；面板会显示实际最大页数。
4. 回车或点「查询」。

#### 结果处理

- **结果在当前页**：立即滚动到该商品，打上橙色（自然位）或紫色（广告位）徽章，右上角弹 toast 显示位置。
- **结果在其他页**：自动跳转到对应 `page=N` 页面，落地后自动高亮定位并弹出 toast。
- **未找到**：toast 提示「前 N 页中未找到该 ASIN 的某某位」。

#### 位置格式

| 模式 | 返回示例 | 含义 |
|---|---|---|
| 自然位 | `3-5` | 第 3 页第 5 个自然位（已排除广告） |
| 广告位 | `2-1` | 第 2 页第 1 个广告位 |

#### 辅助功能

- **历史记录**：按站点独立存储（如 `com`、`co.uk`、`es` 各自分开），最多保留 10 条。
  - 点击胶囊填入 ASIN；
  - 点击 `✎` 改名，留空清除；
  - 点击 `×` 删除单条（二次确认）；
  - 点击「清空全部」清除本站记录。
- **输入匹配高亮**：输入框内容与某条历史一致时，该胶囊变橙。
- **新 ASIN 首次提交**：弹窗提示命名（可留空），方便日后识别。

### 二、查 Listing 关键词（详情页）

1. 打开任意 Amazon 商品的 Listing 页（`/dp/ASIN`、`/gp/product/ASIN`、`/-/xx/dp/ASIN` 等）。
2. 点击右下角悬浮按钮 `🔍 查关键词`。
3. 输入关键词，多个用逗号分隔（中英文逗号、分号均可）：
   - `蓝牙耳机,降噪,续航` → 同时检查这三个词
4. 回车或点「搜索」。

#### 检查范围（6 个区域）

| 区域 | CSS 选择器 |
|---|---|
| 标题 | `#productTitle` |
| 五点描述 | `#feature-bullets` / `#featurebullets_feature_div` |
| 商品描述 | `#productDescription` / `#productDescription_feature_div` |
| A+ 内容 | `#aplus` / `#aplus_feature_div` / `.aplus-v2` |
| 商品详情 | `#detailBullets_feature_div` 等多个候选 |
| 品牌/店铺 | `#bylineInfo` |

#### 结果展示

- 只显示**命中的区域**（绿色行），底部汇总「命中 N/6 个区域」；
- 点击绿色行 → 自动关闭面板 → 滚动到该区域 + 橙色描边高亮 3 秒；
- 全部未命中时显示红底提示「❌ 所有区域均未命中『xxx』」。

#### 输入框清空规则

- 输入框内容末尾有逗号（`,` 或 `，`）时，**点回输入框不会清空**，可继续追加关键词；
- 末尾无逗号时，**点回输入框自动清空**，方便直接粘贴新一批关键词。

## 悬浮按钮

- **位置记忆**：拖动到任意位置后自动保存，下次打开回到该位置。
- **越界保护**：如果保存的坐标超出当前窗口（比如换小屏），自动重置到右下角。
- **拖动 vs 点击**：位移小于 6px 视为点击；大于 6px 视为拖动，不会误触发查询。
- **查询中禁用**：点按钮进入查询状态后暂时禁用，防连点。

## 存储说明

所有数据通过 Tampermonkey 的 `GM_setValue` 存储，**按站点分开**：

| Key | 说明 | 作用域 |
|---|---|---|
| `amz_rank_asin_history:<site>` | ASIN 历史记录 | 每站点独立 |
| `amz_max_pages` | 上次查询页数 | 全局 |
| `amz_query_mode` | 上次查询模式（natural/ad） | 全局 |
| `amz_btn_pos` | 悬浮按钮位置 | 全局 |

`<site>` 取值示例：`com` / `co.uk` / `de` / `es` / `nl` / `co.jp`。

**旧版迁移**：如果从旧版本升级，首次打开时会把旧版全局历史 `amz_rank_asin_history` 迁移到当前站点，然后删除旧 key。

## 性能特性

- **跨页并发**：第 2~5 页用 `fetch` 并发请求，命中即返回，其余请求后台继续完成。
- **自适应间隔**：默认 50ms 错开请求，页数多时总错开时长压缩到 800ms 内，避免等待过长。
- **两遍扫描**：先遍历 `data-asin` 属性找目标，命中后再从头数位置，减少 DOM 查询开销。
- **rAF 节流**：等待卡片加载时用 `requestAnimationFrame` 合并 DOM 变化，避免频繁查询。
- **URL 变化监听**：拦截 `pushState` / `replaceState` / `popstate` / `hashchange`，SPA 导航后自动重新检测并挂载按钮。

## 已知限制

1. **只支持 ASIN 匹配**：不支持 EAN/UPC/GTIN、SKU、FNSKU、标题关键词等模糊匹配。用 ASIN 是最精确的方案。
2. **广告位识别**：依赖 `.AdHolder` 类名和 `Sponsored` 标签。亚马逊 A/B 测试期间结构变化可能导致识别失败，遇到时请反馈页面 HTML。
3. **部分广告无法查到**：顶部横幅、侧边栏广告不属于搜索结果卡，不在查询范围内。
4. **A+ 内容懒加载**：部分 Listing 的 A+ 区域滚动到时才渲染，如果刚打开就搜索可能显示「区域未找到」，滚到底部再搜一次即可。
5. **跨域限制无关**：Console 中出现的 CORS / MIX C004 / sandbox 报错均为亚马逊自身页面问题，与脚本无关，可忽略。
6. **日亚特殊广告**：部分日本站的广告卡使用不同结构，可能影响广告位识别，必要时需单独适配。
